# Living Manuscript Progression Shell Design

**Status:** Implemented for MnAGnosis `1.2.0`.

The Living Manuscript introduces all three disciplines without shipping their
spell works. Truth initiation grants one orientation proof for Definition,
Relation, and Continuance; each track remains at Perception.

The item is a replaceable, read-only view of the holder's server capability.
It stores no progression NBT. Right-clicking it after server eligibility checks
sends one bounded snapshot on core packet ID `5` and opens a client-only
three-tab manuscript screen.

The player-facing tracks are Autogenesis — Definition, Architectonics —
Relation, and Worldliness — Continuance. The four stage names are visible, but
future proof requirements remain veiled.

Existing Tier-6 Ineffable players receive the three proofs and one initial book
on login with deterministic migration evidence. Repeated initiation is
idempotent. A book and Primal Mote craft a harmless replacement.

This slice adds no stage advancement, component, spell recipe, gameplay gate,
or client proof-grant path. Autogenesis remains the first mechanical discipline.
